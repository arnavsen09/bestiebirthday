# 🎉 Happy 16th Birthday, Ojal (OG)! 👑✨

A production-ready, aesthetic, single-page React birthday website built with **Tailwind CSS** and **Framer Motion** (`motion/react`) dedicated to Ojal (School Sports Captain & Drama Queen), created with best wishes from Happy.

---

## 📁 How to Add Your Photos

## 🚀 Quick Start (Local Development)

```bash
# 1. Install dependencies
npm install

# 2. Run the development server
npm run dev

# 3. Open in browser
http://localhost:3000
```

---

## 🌐 Deploy to Vercel & GitHub

1. **Commit and push to your GitHub repo:**
   ```bash
   git add .
   git commit -m "Happy 16th Birthday Ojal! 🎂✨"
   git push origin main
   ```

2. **Import into Vercel:**
   - Go to [vercel.com](https://vercel.com)
   - Click **Add New Project** → Select your GitHub repository
   - Framework Preset: **Vite**
   - Click **Deploy** 🚀

## ✨ Features Included
- **Hero Section**: Playful animated heading *"Happy 16th Birthday, OG! 👑✨"*, subtitle celebrating her Sports Captaincy & Drama Queen status, and interactive *"Unwrap Your Wish"* modal.
- **Moments & Memories Gallery**: 12 curated photo cards with category filtering, hover zoom, and full-screen lightbox modal.
- **Heartfelt Letter**: Glassmorphic letter card with custom styling and the exact birthday message from Happy.
- **The "Sorry" Note**: Sincere and funny closing card with interactive toast pops and heart reactions.
- **Aesthetic K-Drama / Pastel Theme**: Ambient glows, smooth scroll progress bar, acoustic pentatonic chime synth, and confetti particles.
